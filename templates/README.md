# Szablony PDF

Włóż tutaj swoje pliki `.pdf`. Są dostępne na ekranie **Start / Szablony**
po uruchomieniu PrOximAl. Możesz tworzyć podfoldery, np. `Faktury/`, `Umowy/`.
Lista odświeża się przy powrocie na Start lub do okna aplikacji;
można również użyć przycisku **Odśwież**.

- **Dodaj szablony…** kopiuje wybrane PDF-y do tego folderu.
- **Utwórz PDF…** tworzy szablon z wybranym formatem, orientacją, liczbą
  stron oraz opcjonalnym nagłówkiem i tekstem pierwszej strony.
- W edytorze **Narzędzia → Zapisz jako szablon…** dodaje aktualny wynik.
- Dwuklik / **Użyj szablonu** otwiera kopię do pracy, nigdy nie modyfikuje wzoru.
- Powtarzające się nazwy dostają przyrostek `(2)`, `(3)` itd.

Aby usunąć szablon, usuń jego plik z tego folderu. Własne PDF-y są
ignorowane przez Git, aby przypadkowo nie publikować dokumentów.
